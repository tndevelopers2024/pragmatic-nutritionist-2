# Social Media Content Extraction

This directory contains all scraped social media profiles, metadata, links, post texts, YouTube videos/shorts, and media assets extracted from [https://www.pragmaticnutritionist.com/](https://www.pragmaticnutritionist.com/).

## Files

- `social-media-content.md`: Comprehensive breakdown of all social media profiles, handles, icons, links, and content summaries.
- `social-media-content.json`: Complete structured JSON data for programmatic use.
- `youtube-videos.json`: Detailed list of YouTube long-form videos and shorts with IDs, URLs, titles, and engagement stats.
- `verification.json`: Verification manifest comparing scraped channels against live site sources.
